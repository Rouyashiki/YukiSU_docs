# YukiSU Documentation

The site is generated with [VuePress](https://vuepress.vuejs.org/) and [vuepress-theme-plume](https://github.com/pengzhanbo/vuepress-theme-plume).

Product and compatibility claims must be supported by the current [YukiSU source repository](https://github.com/Anatdx/YukiSU). Avoid copying behavior from another KernelSU fork without verifying it in YukiSU.

## Install

```sh
pnpm i
```

## Usage

```sh
# Start the development server
pnpm docs:dev
# Build for production
pnpm docs:build
# Preview the production build locally
pnpm docs:preview
# Update VuePress and the theme
pnpm vp-update
```
