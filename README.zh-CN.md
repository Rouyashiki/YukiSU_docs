# YukiSU 文档站

网站使用 [VuePress](https://vuepress.vuejs.org/) 和 [vuepress-theme-plume](https://github.com/pengzhanbo/vuepress-theme-plume) 构建。

产品功能与兼容性描述必须能由当前 [YukiSU 源码仓库](https://github.com/Anatdx/YukiSU)证实。未经核对，不应直接复制其他 KernelSU 分支的行为。

## Install

```sh
pnpm i
```

## Usage

```sh
# 启动开发服务
pnpm docs:dev
# 构建生产包
pnpm docs:build
# 本地预览生产服务
pnpm docs:preview
# 更新 vuepress 和主题
pnpm vp-update
```
