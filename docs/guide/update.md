# 更新 YukiSU

YukiSU 不是“更新一个 APK，全家一起升级”。管理器、设备里的 `ksud`、启动镜像中的 `ksuinit` 和 LKM 都是不同组件。

## 只更新管理器

- 正式版从 [GitHub Releases](https://github.com/Anatdx/YukiSU/releases) 下载；
- 想试 CI 版，再去设置里明确开启 CI 更新。

CI 更新会检查固定公钥对应的 PGP 签名、APK 签名和构建信息，但测试版就是测试版，签名校验通过不等于它和正式版一样稳。

装完 APK 后先看首页。如果内置 `ksud`、已安装 `ksud` 或 LKM 需要同步，管理器会显示对应状态；没必要看到新版本就把所有东西重装一遍。

## 更新 LKM 和启动组件

需要更新内核侧时，重新走管理器的“LKM 修补/安装”：可以写当前槽位、OTA 后的未使用槽位，也可以只生成镜像。

开始前确认：

- 新 LKM 匹配当前内核 KMI；
- 分区和 A/B 槽位没选错；
- 原厂启动镜像还在；
- 准备部署的组件来自同一套构建。

不要把“随便替换某个 `.ko` 然后重启”当成通用更新法。LKM 实际放在哪、由谁加载，取决于当前启动镜像里的安装布局。

## OTA 后更新

“安装到未使用槽位”只适合这个时间点：OTA 已经完成，但你还没重启切槽。

在页面上核对目标槽位、启动分区和新槽位的 KMI。OTA 把内核一起换了时，旧槽位能用的 LKM 不一定还能继续用。
